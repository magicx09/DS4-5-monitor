# 从刷入到日常使用

## 刷入

下载本项目 Release 的 `DS4-5-monitor-0.01-pico2w-zh-prop16.uf2`，可用同页 SHA256SUMS 核对文件。按住 Pico 2 W 的 BOOTSEL 再插入 USB，把 UF2 复制到启动盘。复制完成后启动盘自动消失，开发板重启。

不要把原上游桌面配置器的自动更新源当成本项目的更新源。本版关闭了 USB CDC 和厂商管理接口，配置主要通过 OLED 完成。USB 仍按手柄兼容身份工作，所以 Windows 中不一定显示“DS4/5-monitor”这个项目名。

从开发版升级到 0.01，配置、配对等保存区地址不变。正常 UF2 升级无需清空配对；擦除整片 Flash 则会清掉保存信息。

## 配对与槽位

1. 用 KEY0 / KEY1 切到配对槽页面，方向键选择空槽，按 △ 切换。
2. 长按 KEY0 两秒开启配对窗口。
3. DS4：SHARE + PS；DS5：创建键 + PS，按住直到灯条快闪。
4. 等待主界面显示连接状态。已配对手柄日后按 PS 即可尝试重连。

如果看到 slot occupied／槽位已占用，先选择空槽；只有准备删除旧配对时才长按 □ 清除该槽。空槽仍无法配对时，再检查扫描识别和 Feature 报告初始化。

## 每只手柄自己的设置

四个槽分别保存手柄配置，不按 DS4 / DS5 两个大类合并。同型号两只手柄也能不同。连接已配对设备或切换槽位时使用对应配置。

示例：DS4 左右握把振动都设为“关”，按 △ 保存；切到 DS5 的槽，左右保留 1.0x，再按 △ 保存。关闭握把振动不关闭扬声器，自适应扳机另外调整。

独立字段包括左右振动、自动触觉、扳机强度、手柄音量／输出选择／音量锁定、音频缓冲、灯条与颜色、回报率和闲置断开等。屏幕亮度、熄屏、方向、板载 LED、GPIO、旁白和 PC 电源策略仍是共用设置。映射和校准保留原有系统，本次没有统一改造成新的槽位配置。

首次从共享设置升级，各槽复制原配置作为起点，包括已保存的音量锁定。之后必须在对应槽按 △ 保存；切槽不会替你保存菜单草稿。清除配对／替换手柄会重置该槽的手柄设置，其他槽保留。“恢复默认”会重置当前槽及共用设置，保留其他槽配置；“清空配对”是另一项操作。

## 声音怎么设置

**只确认 DS4 扬声器通路：**让应用向手柄播放设备输出，OLED 的音频输出选择“扬声器”，确认 Windows 未静音及本地音量合适。若选择“自动”，输出可能跟随耳机插入状态。Windows 设备名称不能反映当前选择的实际播放目标。

**原生 DS5 双路声音：**保持电脑音箱为默认输出、手柄播放端点启用，游戏需要原生识别到 DualSense。需要时关闭该游戏的 Steam Input／虚拟 Xbox 转换，再测试。OLED 音频中启用“锁定音量”并保存，可以防止游戏初始化覆盖手柄功放音量；Windows 端点自己的音量／静音仍然生效。

游戏需要自行提供手柄音轨，固件只负责接收和播放。

## 屏幕操作

- KEY0 / KEY1：沿用页面切换；KEY0 长按两秒进入配对。
- KEY0 + KEY1：按住两秒翻转 180°，继续按到五秒重启。
- 设置页方向键上下选择、左右修改，✖ 进入、○ 返回、△ 保存。
- 连接后主界面右上为真实蓝牙信号条；刚连上未拿到读数时为空框。近距离持续满条属于正常情况。
- 屏幕太暗／熄灭，先检查亮度和自动熄屏设置；I²C 接线模式错误则是另一类问题，见硬件文档。

## 提交问题时

请给出板子和屏幕型号、手柄型号、固件版本、问题出现步骤、是否重启后仍然发生。声音问题补充默认输出、目标应用是否选手柄、是否插耳机、锁定音量是否打开。可以附去掉 MAC 的 OLED 照片；不需要公开账号、蓝牙地址或完整系统设备清单。
