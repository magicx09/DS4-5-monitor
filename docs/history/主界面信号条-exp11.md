# 主界面信号条 exp11

2026-11-08。按确认的预览实现，仅编译 prop16。

固件：`firmware/ds4-experimental/ds5-ds4-signal-exp11-zh-prop16.uf2`

- DS4 / DS5 连接时，主界面标题右侧改为横向蓝牙信号条，替代版本号或 DS4 文本。保留最右侧连接圆点。
- 信号条位于 x=60、y=2，尺寸 56×8；与预览一致。下方地址、电量、手柄图和按键提示保持原布局。充电状态标题也使用该信号条。
- 使用实际 HCI Read RSSI，与原信号页共用缓存及请求限速，最多 10 Hz、同时最多一个请求。此数值为蓝牙 Classic 相对接收功率范围，不是 dBm：0 或正值满条，-30 或更低为空，中间按比例显示。
- 刚连接未获得读数、读取失败时显示空框；断线／重连由原信号缓存逻辑重置。未连接页仍保留版本显示。
- 包含 exp10 按手柄／配对槽独立设置及此前音频修复；无需清空配对或设置。
