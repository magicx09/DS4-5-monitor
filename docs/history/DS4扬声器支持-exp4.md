# DS4 扬声器支持（exp4）

本版在 exp3 的 DS4 基础控制上增加 **扬声器播放**，保留按键、摇杆、触摸板、体感、震动和灯条。按你的要求，USB 和蓝牙两端都不提供麦克风功能。

实现路径：Windows 看到一个 UAC1 扬声器 OUT 接口，格式为 32 kHz、16-bit、双声道；固件把 PCM 分成 128 帧，使用 BTstack 的 SBC 编码器，四帧打包成 DS4 的 `0x17` 蓝牙 HID 输出报告，并由现有 DS4 CRC/发送队列发出。USB 描述符没有麦克风接口，也没有启用 DS4 麦克风报告。

## 固件

- [prop16 UF2](firmware/ds4-experimental/ds5-ds4-speaker-exp4-zh-prop16.uf2)
- [全部 SHA-256](firmware/ds4-experimental/SHA256SUMS.txt)

选择与当前 OLED 设置行高相同的文件。刷写方式沿用之前 exp3；刷写前让板进入 BOOTSEL，复制 UF2 后等待重启。无需清空配对槽。

## 已完成的检查

- 主机测试：355 + 22 + 22 + 1，全部通过。
- prop16：构建、Flash 保留区、core1 RAM 路径、XIP 设置全部通过。
- SBC 编码参数：32 kHz、双声道、16 blocks、8 subbands、loudness、bitpool 25；每帧 112 字节，四帧一个 `0x17` 报告。

## 实机验证顺序

刷写后让 DS4 连接，Windows 应出现一个播放设备；播放系统测试音或短音频即可验证。先确认能枚举播放设备，再确认有声音，最后观察持续播放约 1 分钟是否断连或爆音。exp3 已验证的控制功能应继续保持。

如果 Windows 仍只显示手柄而没有播放设备，记录设备管理器里的接口数量和固件 OLED 状态；如果能播放但无声，记录 Windows 音量/静音状态和是否能持续连接，这两类现象对应不同层的问题。
