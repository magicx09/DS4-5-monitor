# 每只手柄独立设置：exp10 / prop16

2026-11-08。以四个配对槽分别保存手柄设置。同型号的两只手柄也可使用不同设置；仍然一次连接一只手柄。

## 固件与操作

固件：`firmware/ds4-experimental/ds5-ds4-profiles-exp10-zh-prop16.uf2`

1. 刷入 exp10 后连接 DS4，确认当前配对槽对应 DS4。
2. 在 OLED 设置的振动分组，将“左握把振动”和“右握把振动”都降到“关”，按 △ 保存，确认显示“已保存”。
3. 连接 DS5，确认切换到了它自己的配对槽；左右握把振动保留需要的倍率，例如 1.0x，然后按 △ 保存。
4. 以后切换配对槽或已配对手柄从自己的槽连接，会加载该槽的设置。无需每次手动开关震动。

关闭左右握把振动涵盖普通震动和 DS5 音频触觉反馈；自适应扳机由独立的扳机设置控制。关闭震动不关闭扬声器。

## 独立保存的范围

- 左右握把振动、自动触觉反馈模式／强度／滤波、扳机效果强度。
- 手柄扬声器音量／增益／输出选择、音量锁定、音频缓冲和已有麦克风相关配置字段。没有新增麦克风功能。
- 灯条模式与自定义颜色。
- 回报率、手柄模式、音频包模式、闲置断开设置、放回底座断开设置。

OLED 亮度、熄屏时间、屏幕旋转、手柄唤醒屏幕、板载指示灯、GPIO、旁白和电脑电源相关选项仍是桥接器共用设置。按键映射和校准仍沿用原有存储机制，本版没有将其改为每槽独立。

Windows 的默认播放设备、系统音量及游戏音频会话由电脑管理，不属于本版的槽位设置。

## 升级与保存行为

- 原闪存分区和配对表位置不变，不需要为了升级清空配对。
- 首次启动时，将原有共享手柄设置复制为四槽的初始值，包括已保存的音量锁定。之后各槽分别保存。
- 菜单修改后应在该手柄的槽中按 △ 保存；切槽本身不会把菜单未保存的修改写入闪存。
- 已应用到运行配置但尚未保存的修改，在本次运行期间按槽保留；重启恢复已保存的值。切槽会丢弃旧手柄仍停留在菜单编辑副本里的未保存修改，防止误写到新手柄。
- 清除配对或替换该槽手柄会重置该槽的手柄设置。同一蓝牙地址忘记后重新配对，也不会恢复已删除的旧配置。其他槽不受影响。
- “恢复默认”恢复当前槽的手柄设置及共用设置，保留其他槽的独立设置；屏幕方向和配对记录沿用原有保留行为。
- exp9 固件文件已保留。旧固件不理解独立配置；回退后保存设置可能擦除新增配置页，再升级会重新迁移共享值。

## 实现与验证

在原 CONFIG 扇区第二个 256 字节页保存四份带 CRC 的配置记录，第一页面原 Config 布局不变。每份配置绑定槽位、蓝牙地址与配对代数，避免清空后旧设置复活。所有配置写入路径均保留第二页，切槽时同步使 OLED 缓存失效。

左右振动倍率新增 0（菜单显示“关”）。游戏输出与固件主动下发的 DS5 状态报告均遵守当前倍率，防止音量／灯条更新重新带入未缩放的震动。

执行 `python dev.py ds4`：只编译 prop16 固件。425 项测试通过：默认逻辑 368、prop14 渲染 22、prop16 渲染 22、DS4 生命周期 1、原生音频状态 10、USB 描述符 2，启用 ASan/UBSan。覆盖升级、槽位切换／重启、未保存修改隔离、共享字段保存、清空后同地址重新配对、替换手柄、写入失败、记录损坏、恢复默认和震动关闭。
