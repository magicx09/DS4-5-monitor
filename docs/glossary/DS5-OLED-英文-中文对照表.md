## 建议优先核对

本版已完成的重点调整：

1. `Complete → 充电完成`，避免和低电量字节 80% 冲突。
2. `RT → 实时`、`Poll rate → 回报率`、`double/single → 双包/单包`。
3. `Haptics → 触觉反馈`、`AutoHap → 自动触觉反馈`。
4. `Spk volume/boost → 扬声器音量/增益`、`Mic used/level → 麦克风来源/电平`。
5. `Gyro Tilt → 体感倾斜`、`Identify → 识别手柄`。
6. 灯条 `FAV → 预设`、`LIVE → 实时`、`Breathing → 呼吸灯`。

诊断页仍保留 `麦解、麦 i/b/u、核1、原/触` 等极短缩写，因为 12px 字体下屏幕宽度有限；其完整含义见上表。
